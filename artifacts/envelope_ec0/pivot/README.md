# EC0-P pivot artifacts

This directory contains normative additions required before the v1 EC0 corpus
can be migrated to sidecar schema v2.

- `boundary_limited_propagation.yaml` — AM8 semantic policy and ten
  coordinate-free scenarios.
- `boundary_metamorphic_matrix.yaml` — invariance/semantic-change verdicts for
  the AM8 scenarios.
- `ec0-p-boundary-limited-propagation.svg/png` — consolidated visual review
  sheet showing before, exact event, and requested-alpha-beyond-capacity states.

These artifacts specify v1 capability limits. They do not authorize obstacle
bypass, front branching, path choice, or merge behind a hole. That capability
belongs to EC8+.
