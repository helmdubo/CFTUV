GOAL. Inside a domain's certified width interval its exact tick is P0 + slope * dwidth with the SAME structure as a full materialization, because every
decision that can change the structure as the width moves is a NAMED EVENT of the alpha-free event table (or a named refusal). Then the incremental tick
needs no reconciliation (verification) ticks, and drag_exact_ticks can become the default.

3. DESIGN
   a) EVENT TABLE EXTENSION (law COVERAGE_CLIP_AND_DECISION_EVENTS_V2; EventTableV2 = per-kind sorted (lo, hi) arrays + running_hi, like EventTableV1)
      Recording: the cold/miss run of a domain (the one that already records the step certificate and the exact parametric slopes) records a DECISION
      TAPE: every predicate call of section 1 A/B as (kind, operand vertex keys or operand values, threshold, outcome). Operands are named by vertex key
      wherever the code works on `points[key]` / `positions[key]` / `facts[(region, key)]` (tessellation, partition, silhouette, source_lift, assemble);
      the Rust W1 stage emits its own tape (it owns tessellation/partition when NATIVE). Slopes come from the parametric certificate (keyed by vertex key).
      Solving (alpha-free given the record, so it lives in the preparation memo next to EventTableV1):
        A1/A3 identity-or-isolated-root, A2 quadratic: exact SqrtSum sign at rational w + bisection to a 2^-40 relative interval (outward), the same
          EventTableV1 entry shape; closed forms only as cross-check.
        B1-B4, B6, B7: interval arithmetic over w-subintervals of the SAME formula the kernel evaluates (outward rounding, as K/interval.py:88-140 does),
          widened by an a-priori binary64 error bound of the routine; recursive bisection until each subinterval either excludes the threshold (decision
          constant) or is narrower than 2^-30 relative (event band [lo, hi]). Polynomial roots (section 1 degrees) only as a test oracle.
        B5 order: adjacent pairs of the sorted keys must stay separated on the interval (same band machinery on key differences). Exact ties and noise ties
          (gap below the rounding bound) get the witness ORDER_TIES_INDEPENDENT_V1 when the tied candidates touch pairwise disjoint faces (merge decisions of
          disjoint pairs commute, so the greedy result is order-free inside the tie group); otherwise the named refusal LAZY_ORDER_NOISE (domain recomputes).
          Optional law change (owner decision, answer-changing, needs its own DECISIONS line): SILHOUETTE_TOPOLOGY_V2 with an exact dihedral class
          (same source plane -> exact 0) instead of float noise.
        A5 contact window, A6 reach cap: rational bounds copied in.
        C names: no event. D numbers: no event.
      Named event kinds (EventKindV1): COVERAGE_ARRIVAL, CLIP_LINE_CROSSING, CLIP_SOURCE_VERTEX (existing), COINCIDENCE, ORIENTATION, AFFINE_UV_IDENTITY,
        SURFACE_LOCATE, CONTACT_SIGN, REACH_CAP, SILHOUETTE_UV_FIT, SILHOUETTE_MERGE_CHORD, SILHOUETTE_VERTEX_CHORD, SILHOUETTE_UV_SLIDE, SILHOUETTE_ORDER,
        CELL_DIAGONAL_CHORD, HOST_POSITION_FLIP. AlphaIntervalV2 records low/high AND the kind + tape index that limits each side (rule 4: the end of an interval
        is a named event). UNCERTIFIED becomes empty for the product law (SOURCE_FACES_CLIPPED_V1 + SILHOUETTE_TOPOLOGY_V1); any law/stage without a tape
        keeps a non-empty UNCERTIFIED and is never served lazily.
      Refusals of the table (interval collapses to a point, named): TAPE_INCOMPLETE (a predicate site ran without recording), SLOPE_MISSING (operand key
        without certificate slope), BAND_UNRESOLVED (bisection budget), PAIR_LIMIT (existing), plus the existing PARTITION/FACE/LINES reasons.
      AT_EVENT at alpha0 (building e4d13373 at 0.2239): ONE_SIDED records - the miss run at alpha0 is answered in full, and a second record is taken at the
        first recompute inside the open interval on the side the drag moves to (LAZY_AT_EVENT_ONE_SIDED), so the domain stops recomputing every tick.
      Files: K/interval.py (V2 table, AlphaIntervalV2, kinds), new K/decision_tape.py (tape + solver, Python reference), call sites in K/silhouette.py,
        K/tessellate.py, K/convex_partition.py, K/mesh.py, K/coalesce.py, K/clip.py, K/clip_cells.py, K/source_lift.py, K/lift_surface.py, K/assemble.py,
        K/domain.py (_step_facts, fix of the triangles=() gap at 1084), K/step.py; N/cftuv-mesh/src (tessellate.rs, partition.rs, predicates.rs: tape out),
        N/cftuv-clip (ears), N/cftuv-python/src/materialize_w1.rs (tape in the result); kernel/tests (new test_decision_events.py), tests/test_architecture.py.

   a) Exact cross-checks: for every domain of both frozen scenes and the field corpus (E:/cftuv_native_corpus read-only inputs + the pickled preparations of
      capture_focus.py), K random rational widths inside each V2 interval (uniform + 1e-9-relative neighbourhoods of each recorded event end, both sides) ->
      full materialize vs evaluate_lazy: answer_differences() empty (batch canonical bytes equal, except the named price articles), structure signature

      each recorded event end must either change structure or be explained by the tape (event was conservative) - counts both, so over-conservative bands
      are measured, not hidden. The 1146c49e case is a fixed regression test (interval V2 high == SILHOUETTE_UV_FIT at 0.04851891400735791 +- band).
   b) Mutants (each must be killed by the sweep or by kernel tests): drop one tape site per kind; flip a predicate outcome on the tape; shift a recorded slope by
      one ulp; widen/narrow the silhouette tolerance by 1 ulp without re-solving; reorder tied silhouette candidates; disable the tie witness; drop the relabel
      step; reuse a record of another (preparation, interval); swap lo/hi rounding direction of a band; skip TAPE_INCOMPLETE detection. A test in
      tests/test_architecture.py enforces that every predicate function of K/ (orientation, shoelace_sign, segments_cross, uv_fit_residual, _within, ...)
      called by materialize is reached through the tape or listed alpha-free (the executable form of "no uncertified decision").
   c) tree_ab IDENTICAL: commit and cold presses of tools/blender_tree_ab.py (base = main, branch = phase D) IDENTICAL on both scenes after every stage
      (lazy path never feeds COMMIT in phase D); for phase D2 additionally lazy-commit vs cold IDENTICAL.
   d) Domains that stay approximate: developable / unfold domains (PARAM_NON_AFFINE_DEVELOPABLE_OFFSET, K/parametric.py:27-30): the BATCH is exactly affine
      and is served by the kernel path like any other; the host offset along angle-weighted normals and the weld miter are not affine. Host rule: such a
      served domain recomputes its offset with the host's own code from the lazily evaluated batch (same function as the commit) - then it is exact too, and
      only the model-frame tier (float slopes) is approximate: those domains are drawn by the model between ticks and named LAZY_DEVELOPABLE_HOST_OFFSET
      in telemetry; the tick itself is exact. Domains whose tape refuses (TAPE_INCOMPLETE, ORDER_NOISE, BUDGET_MARGIN) recompute every tick, named.

5. RISKS AND STOP RULES
   Risks:
   R1 Missed decision site (a predicate not on the tape) -> a wrong "exact" tick. Mitigation: architecture test of 4b, shadow verify in the field sweep,
      commit stays full. STOP if the sweep finds any LAZY_VERIFY_MISMATCH that is not traced to a missing tape site within one day.
   R2 Float bands unsound (error bound of a binary64 routine underestimated). Mitigation: bound derived per routine and tested against exhaustive bisection
      on the corpus; bands are outward. STOP if any band test needs a hand-tuned factor.
   R3 Order noise (B5) makes many domains LAZY_ORDER_NOISE (cover: 51 / 1046 have ties today). STOP-AND-ASK if the witness leaves > 5 % of domains
      unserved: then the owner decides on SILHOUETTE_TOPOLOGY_V2 (exact dihedral class), an answer change.
   R4 Interval loss: new kinds shrink intervals so much that recomputes dominate. Evidence says small for silhouette (0 events within +-10 %); unknown for
      A2 on fans/caps. STOP if the median V2 headroom above alpha0 falls below 2 % on either scene (the incremental tick would no longer beat lean).
   R5 Tape cost on miss runs (Python tape on every predicate of a cold run). Budget: <= 15 % on the cold button; STOP and move the tape to Rust first if more.
   R6 Memory: LazyRecord with exact numbers per domain x 3. STOP if a worker exceeds the 32 MB store with the records (then 1 record per preparation).
   R7 Budget refusals (B9) are not predictable: a lazy tick may show a domain the full path would refuse. Mitigated by LAZY_BUDGET_MARGIN and full COMMIT.
   R8 Names: a hash relabel bug silently renumbers regions; covered by batch byte equality in 4a (structure signature alone would not see it).
   R9 Collision with rust/drag-quick: the record key equals its PARAMETRIC memo key; rebase phase D on it, never edit that branch.
   Global stop rule: phase D does not ship any default change before the six conditions of 3d hold; each stage lands behind CFTUV_LAZY (default off) and
   with tree_ab IDENTICAL.
