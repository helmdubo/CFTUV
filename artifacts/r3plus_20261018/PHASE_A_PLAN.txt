2. WHAT IS STILL PYTHON, AND ITS HAZARDS
   - sympy: unit vectors x/sqrt(q) under the Gram metric (_unit_g, _owner_normal_g), the density angle predicate (sqrt(|a||b|), cos(pi r)), srepr texts as keys of the
     transaction memo (_density_srepr) - the radicals are the CURRENCY of GeometryContext, i.e. of DOMAIN_BUILD/ARRIVAL/BRIDGE/PRODUCE consumers too.
   - mpmath: interval sign decisions behind _density_exact_sign (precision ladder; only the exact sign is the answer, the ladder is cost).
   - Fraction: chain stations, validation_metric, evaluation geometry snapping (robust/grid.snap_value), corner fold sin^2.
   - Decimal: CertifiedDecimalIntervalV1 angle measures, context precision (snapshot_check already mirrors the context check).
   - binary64: chain-station filter _beyond_by_floats uses float ** 2 = C pow (libm) - sound filter with 1e-6 margin, the exact path decides the rest,
     so a 1-ulp pow difference cannot change an answer (the port must still reproduce the filter verdicts to stay cost-identical: no counter reads it).
   - cost counters on this path: symbolic_backend.BACKEND_COUNTS (angle certificate sign), Density work articles (replayed by density_op), exact work budget.
   - per-call shim cost: density_pin.runtime_stale re-freezes 20 constants and 83 class shapes on EVERY Density call (~1.07 ms warm, standalone) - the ANGULAR lesson.
