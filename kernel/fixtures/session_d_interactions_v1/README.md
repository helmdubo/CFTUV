# Session D EC2.5 exact interaction corpus

This directory is the single declarative fixture source for Session D
resolved-coverage interactions. Every declaration in `cases.json` is executed
by `tests/test_session_d_fixture_corpus.py`; no case is an inert checklist row.

The corpus starts from accepted Session C-R1 reference compilation and raw
coverage contracts. It tests exact front-arrival laws, mutual-arrival
certificates, and `INTRAPATCH_POLICY_B_V1`. Before mutual arrival the resolver
records no interaction. At and after mutual arrival it partitions only
existing exact contributions on the equality locus and creates no matter.

C13 cases keep the third Strip source outside the Angular seed. The third
Strip competes with the actual exposed K0/K1/K2 Angular profile boundary.

The cases intentionally include exact rational events, holes, endpoint-only
Cap contact, explicit self-contact, independent same-alpha contacts, and named
fail-closed outcomes for unsupported multiway or coincident arrivals.

`d_r2_atomic_point_contact_cases.json` is the accepted additive D-R2 contract
corpus. It admits only atomic ownerless point-contact identity batches:
zero-dimensional exact loci, complete `PointContactRecordV1` evidence,
pairwise-disjoint positive-area interiors, and no ownership dependency.
Positive-length loci, positive-area overlap, or ownership requirements remain
`MULTIWAY_INTERACTION_POLICY_UNPROVEN`. The original 23 Session D cases remain
unchanged.

The corpus does not define ownership, station/UV flow, tessellation,
`GeometryBatch`, event scheduling, Blender/native execution, Voronoi, SDF,
rasterization, tolerance predicates, or arrival reconstruction from emitted
polygons.
