### 1. Что мы строим

Blender-аддон (4.1+) полупроцедурной UV-развёртки и wrap-around
декалей для AA-AAA архитектурных игровых ассетов. Пользователь —
художник; правит выбором seam-рёбер, шириной (drag) и разметкой,
НЕ подбором чисел.

**Движок декалей = ровно один пайплайн (compiled strict SEAMS):**

```
scope -> rail/chart plan -> evaluator -> DecalGeometryFace -> materializer
```

Всё остальное (direct ribbon producers TOP/BOTTOM/CORNERS,
исторический decal_network.py, legacy SEAMS fallback) вырезано в
архив срезом S0.

**Северная звезда: криволинейные и сферические поверхности (R3).**
Каждое решение рефакторинга проверяется вопросом: «не запекает ли
этот контракт планарность?» Лента обязана уметь облегать сферу,
трубу, арку; см. §5 «curvature-readiness».

### 2. Карта потоков данных (центральный предмет рефакторинга)

Целевая цепочка; каждый слой потребляет ТОЛЬКО выход предыдущего:

```
Blender BMesh источника (+ matrix_world preflight: reject
non-uniform/shear/mirror/degenerate ДО всего)
    |
    v
ANALYSIS  ->  AnalysisBundle:
    PatchGraph        # ТОЛЬКО топология: patches, классификация,
                      # chains, boundary; никакой геометрии
    PatchSurfaceIR    # ЕДИНСТВЕННЫЙ источник поверхности:
                      #   SourceFace: face_id, patch_id,
                      #     vertex_cycle, edge_cycle,
                      #     polygon_normal, triangle_ids
                      #   SurfaceTriangle: triangle_id,
                      #     source_face_id, vertex_ids,
                      #     physical_edge_ids, triangle_normal
                      # tessellation = Blender loop-triangles,
                      # НЕ произвольный fan
    AnalysisCapabilities  # версии схем; несовместимость ->
                          # fail-fast DECAL_ANALYSIS_SCHEMA_UNSUPPORTED
    |
    v
WorldDecalRequest --[MetricContext: fingerprint матрицы,
    uniform_scale; конверсия РОВНО ОДИН РАЗ]--> LocalDecalRequest
    (WorldDecalSettings и LocalDecalSettings — РАЗНЫЕ типы)
    |
    v
DecalScopeCompiler: выбранные физические рёбра -> chain uses ->
    топологические компоненты
    |
    v
DecalBackendRouter -> RailPlanarPlan | PatchVoronoiPlan
    (tagged union; строковые имена backend'ов запрещены)
    |
    v
DecalEvaluator: compile-static план; drag меняет ТОЛЬКО extent
    (инвариант I1); никакой трассировки в кадре
    |
    v
GeometryBatch (immutable):
    faces (tuple), vert_keys (identity!), UV facts, diagnostics
    |
    +--> GPU PreviewPort      # рёбра/топология ТОЛЬКО по vert_keys;
    |                         # позиции — только в буфер
    +--> BMeshMaterializer    # транзакционный: temp BMesh ->
                              # полная валидация -> publish/swap
```

Правила потребления:
- Чтение «через голову» запрещено: evaluator не читает BMesh
  источника; GPU не выводит топологию из координат; материализатор
  не переспрашивает analysis.
- Реконструкция исходного объекта из производного запрещена
  (не восстанавливать полигоны из fan-треугольников, контур из
  сегментации цепочек, форму угла из crop-полигонов).
- Всё, что вычислено и эмитировано, дальше ЧИТАЕТСЯ, не
  пересчитывается («один источник, много читателей»).

### 3. Инварианты — ревизия (пользователь дал добро на пересмотр;
это итоговый действующий набор)

ЖЁСТКИЕ (проверены производством; нарушение = дефект ревью):

- **I1 Compile-static (S1).** Трассировка, станции, конкуренция,
  freeze — на compile. Drag меняет только материализованный
  extent. `Construct()` в кадре запрещён.
- **I2 Детерминизм.** Бит-идентичная регенерация; инвариантность
  к порядку перечисления рёбер, направлению обхода и флипу
  нормалей source-меша.
- **I3 Ноль числовых выборов поведения.** Пороги/углы/округления
  не выбирают ветку исполнения. Числа — только семантика:
  ширина, `DECAL_COPLANAR_DOT` (единственный предикат излома,
  сейчас cos 4°; смена — только решением пользователя),
  бюджеты. `_RAIL_PLANAR_DOT` (1-1e-10) — допуск арифметической
  представимости: только именованный fail либо counted
  терминация, никогда выбор геометрии.
- **I4 Один источник, много читателей.** Один идеальный объект —
  одно представление. Действует для: формы угла (CornerModel),
  контакта с границей (станционная точка), станций маршрута,
  vert_keys.
- **I5 Provenance тотальна.** Каждый эмитированный элемент знает
  source-грань, source-ребро, route и станцию.
- **I6 Preview == confirm.** Единый evaluator и ЕДИНАЯ валидация;
  состояние, достижимое в preview, не может падать на confirm.
- **I7 Fail-fast, именованно, честно.** Тихих фолбэков и
  деградаций нет. Неподдержанное — именованная ошибка; недоступная
  фича — выключенная кнопка, не подмена поведением.
- **I8 Насыщение.** Ввод за пределами ёмкости поверхности
  (ширина >> меша) — валидное состояние: клампы counted, не
  ошибки (правило RR8d).
- **I9 Полевая приёмка первична.** Гейт §0d.0: отчёт полевого
  фикса обязан содержать рендер ракурса пользователя и
  по-стрелочное «было -> стало». Тесты геометрии — на ИТОГОВОЙ
  спроецированной 3D-геометрии, не на промежуточных структурах.

ПЕРЕСМОТРЕННЫЕ / СНЯТЫЕ (не воспроизводить старые формулировки):

- ~~«PatchGraph topology-only»~~ -> AnalysisBundle: топология в
  PatchGraph, поверхность в PatchSurfaceIR. Текущие
  surface-данные внутри PatchNode под комментарием «debug» —
  фактический production-вход; узаконить переносом, не оставлять.
- ~~«интерьер бит-идентичен»~~ -> бит-идентичность только вне
  зоны среза (урок «нашлёпок»: противоречивое требование родило
  оверлей).
- ~~RR9c min-reach (связывание сторон торца)~~ — ОТОЗВАН.
- ~~«BEVEL = MITER включая столкновения»~~ -> RC5a: join не
  меняет свою ленту, но определяет материю угла для всех
  остальных.
- ~~«переключение join без recompile»~~ -> join style — compile-
  вход угловых структур; toggle перевыводит угловые-локальные
  структуры (S1 сохранён: в drag пересчёта нет).
- ~~«валидировать весь меш»~~ -> RV1 в силе: валидация по
  footprint; грязная грань вдали не валит компиляцию; ранние
  именованные ошибки — да, полномешевый гейт — нет.
- Правила эпох до движка (пять corner-политик bands-оракула,
  atlas/GL-детали, E-acceptance) — НЕ контракты рефакторинга;
  пересматриваются после TRANCHE S.

### 4. Каталог болезней (анти-возрождение старого дизайна)

Каждая болезнь реально случалась в этой ветке и стоила итераций.
Признаки — для самопроверки и код-ревью.

- **Б1 «Два представления одного объекта».** Случаи: rail-backend
  реконструировал полигоны из fan-треугольников; GPU строил рёбра
  по координатам, округлённым до 1e-5, игнорируя vert_keys; форма
  угла жила одновременно в crop, arrangement, collision, emission
  и UV (пять итераций BEVEL); граница ленты рисовалась хордой при
  контакте, скользящем по контуру. Признак: одно понятие
  вычисляется в двух местах / выводится из производного.
- **Б2 Числовой выбор поведения.** Случаи: знаковые convexity от
  нормали/обхода (инверсия углов на конкретной стенке); округление
  координат как критерий склейки. Признак: `if angle < X`,
  `round(...)в ключе`, `abs(...) < eps` в ветвлении поведения.
- **Б3 Нашлёпка вместо среза.** Скольжение торца реализовали
  отдельными faces ПОВЕРХ ленты (двойное покрытие). Признак:
  новый слой геометрии там, где должен меняться существующий.
- **Б4 Тихий фолбэк.** Пустые side_face_normals молча подменялись
  patch-average (неверная геометрия wrapped-стен); README обещал
  legacy fallback, которого нет. Признак: `or default` на
  семантических данных.
- **Б5 Тест промежуточного вместо финального; счётчики вместо
  глаз.** BEVEL-тест проверял треугольный crop, а финальные грани
  имели 5-6 вершин; три полевых провала подряд при зелёных
  счётчиках. Ответ: гейт §0d.0 + тесты на итоговой геометрии.
- **Б6 Связывание независимых сторон.** min-reach обрезал здоровую
  сторону торца по короткой. Признак: «синхронизируем/выравниваем
  две стороны» без существующего инварианта.
- **Б7 Производная конструкция вместо объекта.** Контакт
  останавливался на конце ЦЕПОЧКИ (артефакт сегментации), тогда
  как физический КОНТУР продолжался. Признак: терминация/решение
  на границе внутренней структуры данных, а не объекта сцены.

### 5. Целевые контракты (скелеты)

Immutable dataclasses, enums вместо строк, невалидное состояние
невыразимо. Curvature-readiness обязательна: контракты не
предполагают планарность.

```python
@dataclass(frozen=True)
class SourceFace:
    face_id: int; patch_id: int
    vertex_cycle: tuple[int, ...]
    edge_cycle: tuple[int, ...]
    polygon_normal: Vec3
    triangle_ids: tuple[int, ...]

@dataclass(frozen=True)
class SurfaceTriangle:
    triangle_id: int; source_face_id: int
    vertex_ids: tuple[int, int, int]
    physical_edge_ids: tuple[int, int, int]
    triangle_normal: Vec3           # РЕАЛЬНАЯ, не унаследованная

@dataclass(frozen=True)
class MetricContext:
    source_matrix_fingerprint: tuple
    uniform_scale: float

class DecalBackendKind(Enum): RAIL_PLANAR; PATCH_VORONOI
class CornerJoinMode(Enum): MITER; BEVEL
class PreviewFailurePolicy(Enum): CLEAR                # дефолт и
    # пока единственная политика: «пусть ломается видимо» —
    # решение пользователя; GPU и mesh адаптеры ОБЯЗАНЫ совпадать

@dataclass(frozen=True)
class CornerModel:
    """Единственный источник формы угла (срез S-CM).
    V + P1/P2, ПРОЧИТАННЫЕ из уже клипнутых внешних углов
    собственных strip-сегментов (общие vert_keys), + join.
    Из него derive: collision domain, ownership, UV, проекция,
    3D-эмиссия. Родословная: угол = точечная ячейка Вороного
    (прототип пользователя); MITER=апекс, BEVEL=хорда(P1,P2) —
    два режима ОДНОЙ модели, не две реализации."""
    corner_vertex_id: int
    spine_edge_id: int
    side: BandSide
    p1_key: VertexKey; p2_key: VertexKey
    join: CornerJoinMode
```

Curvature-readiness чеклист (для КАЖДОГО контракта S):
- нормали — по треугольникам, не по патчу;
- предикат излома — единственный (`DECAL_COPLANAR_DOT`);
- внутренние координаты ленты — нейтральные (s, r): s — станции
  вдоль spine, r — накопленная длина поперёк; публичный
  UV-контракт (U поперёк, V вдоль) отображается один раз в R4;
- CornerModel не предполагает in-plane: на кривизне угол живёт на
  ней же (R3), плоскость сектора — частный случай;
- rails — топологические маршруты по рёбрам меша (surface-native,
  RM1): на кривизне геометрию несут они, не аналитика плоскости.

### 6. Программа срезов

- **S0 — АРХИВ-CUT** (детальный контур — §0g workplan):
  архивная ветка, физическое удаление поколений 1 и 3, именованные
  fail'ы отрезанных режимов, disabled-кнопки, синхронизация доков.
  Движок в S0 не трогать.
- **S1 — Контракт поверхности:** PatchSurfaceIR + Blender-
  consistent tessellation + реальные нормали; footprint-scoped
  preflight (именованные ранние ошибки; RV1 — без полномешевого
  гейта); GPU-рёбра по vert_keys; PreviewFailurePolicy=CLEAR в
  обоих адаптерах; dihedral по per-segment парам локальных
  нормалей обеих chain uses. Регрессии: вогнутый U-образный n-gon,
  non-planar quad/n-gon, reversed winding, сверка
  площади/containment с Blender tessellation.
- **S-CM — CornerModel:** единая пост-клип модель угла (контракт
  выше). BEVEL возвращается в UI только отсюда. Приёмка на
  финальной 3D-геометрии: BEVEL-грань = ровно 3 вершины; чужой
  фронтир доходит до хорды; own-segments бит-идентичны MITER;
  перекрытие соседних углов на большой ширине — через общую
  конкуренцию.
- **Ревизия заготовок** R1.9 (насыщение, `3d1abd8`) и R2-freeze
  (`94bb679`): принять или переделать на новом фундаменте;
  свежие BEVEL-коммиты (`6fc1e08`, `3a37745`) — материал, не
  фундамент.
- **R2 — конкуренция/freeze** (RC1-RC3, RF7, RR10: нить — один
  route, ДВА чтения станций, freeze-локус).
- **S2 — Типизированные границы:** World/LocalDecalSettings,
  MetricContext, AnalysisCapabilities fail-fast,
  DecalSessionController (operator — тонкий перевод событий),
  immutable DTO.
- **R3 — Кривизна:** сфера облегает (RF2), полюс-CAP, непланарный
  скоуп RR10; полевая приёмка на half_sphere.
- **S3 — Декомпозиция decal_voronoi.py по ownership** (compile /
  diagram / clipping-arrangement / chart transitions / lift /
  corner policy / UV / diagnostics) — только после контрактов;
  механическое разрезание запрещено.

### 7. Рабочие соглашения (обязательны)

- **§0f Голос исполнителя:** противоречивая/вредная директива —
  ОБЯЗАН возразить с вариантами (молчаливое исполнение брака —
  процессный дефект); свобода реализации в рамках контрактов;
  предложения по канону — блоком «Особое мнение»; тихие отклонения
  запрещены.
- **§0d Тестирование:** ярус-1 pre-commit; ярус-2 на срез — ОБЯЗАН
  завершиться (таймаут != зелёный; тяжёлые atlas-тесты за маркером
  `atlas_frozen`); полевой набор шести объектов (rounded_wall.001,
  rounded_wall_noise_top, sagging_wall, wall_noise_top,
  half_sphere, building) — noise-top/half_sphere дают ожидаемые
  именованные отказы до R3.
- **Гейт §0d.0:** полевой фикс report-ready только с рендером
  ракурса пользователя и по-стрелочным «было -> стало».
- **Дизайн-стопы:** потребность в числовом tie-break; конкуренция
  без ответа станционной метрики; неоднозначность merge; конфликт
  с каноном — стоп с фактами, не импровизация.
- **Git:** ветка `claude/blender-decal-corner-preview-yq4lir`;
  на отказ push — fetch+rebase (ревьювер пушит параллельно);
  `.blend` не сохранять; установленный аддон синхронизировать и
  сверять SHA-256; commit-подпись сборки видна в панели.
- Финальный арбитр всегда — пользователь в Blender на живой сцене.
