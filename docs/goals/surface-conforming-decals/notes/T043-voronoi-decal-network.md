# T043 — Seam decal network: α-clipped nearest-branch partition

Manual `Decal Seams` переведён с последовательности «независимые ribbons →
junction cut → радиальные сектора → dissolve поперечных рёбер»
(T035/T037/T039/T042) на единое глобальное разбиение по образцу
segment-Voronoi (Johannsen, Edge Decal Generator), адаптированное для
многоповерхностных corner-сетей. Новый модуль — `cftuv/decal_network.py`,
чистая геометрия без bpy/bmesh.

## Ключевые решения

- **Внутренняя метрика вместо 3D.** Постоянная ширина декали — геодезическое
  расстояние; corner из планарных owner surfaces изометричен плоскости.
  Partition считается в 2D на каждой owner offset-плоскости, лифт в 3D —
  отдельный слой (offset вдоль normal, corner spine на пересечении
  offset-плоскостей, junction core как least-squares, `_lift_position`).
- **Не полная Voronoi-диаграмма, а α-clipped ячейки.** Ячейка ветви =
  α-полоса вокруг spine ∩ полурегионы «ближе ко мне». Прямой клиппинг faces
  имплицитной функцией f = d_other − d_own (bisection по рёбрам + уточнение
  хорд по sagitta) вместо sweepline-ядра — робастно и достаточно, потому что
  вход ограничен mesh edges и малой валентностью junction.
- **Сайты — ветви, не сегменты.** Внутри ветви поперечные границы не
  возникают по построению. Коллинеарные продолжения в junction
  (`DECAL_NETWORK_CONTINUATION_DOT`) сливаются в сквозной сайт: непрерывный
  UV через узел, критерий геометрический, «главная ветка» не выбирается
  произвольно.
- **Ghost-сайты через fold не нужны.** Любой путь с соседней поверхности
  пересекает fold-линию; если fold выбран как ветвь, его spine всегда
  строго ближе. Per-surface сайтов достаточно — это доказуемо, а не
  эвристика.
- **Ties в общих vertex regions** двух ветвей, оканчивающихся в одном узле,
  разрешаются retraction обеих spine на δ ≪ weld: tie-регион схлопывается в
  угловую биссектрису (усреднённая divider-линия T039 получается как частный
  случай), имплицитная функция получает чистую смену знака.
- **Сшивка водонепроницаема по построению**: spine-станции и junction cores
  идут через единый registry по source vert index (`('sv', vert)` ключи),
  общий для крыльев на разных поверхностях. Разрез ячейки fold-линией не
  нужен — сайты каждой поверхности уже заканчиваются на её spine.
- **Смена поверхности внутри ветви** режет сторону на maximal подпути;
  на станции разреза добавляется connector-треугольник (аналог legacy
  BEVEL); почти копланарные разрезы схлопывает финальный weld.
- **Round caps на α** закрывают reflex-угловые промежутки junction
  (pac-man дыры legacy-пайплайна) и делятся биссектрисами между соседями.

## Результаты на fixtures (tests/test_decal_network.py)

- Planar T: ровно 6 faces; стем доходит клином до узла, divider-вершины
  (±α, −α); UV bar непрерывен сквозь узел; поперечное endpoint-ребро stem
  отсутствует по построению (T042 — частный случай).
- X-junction: 8 faces, партиция диагоналями, оба bar UV-непрерывны.
- Trihedral: общий offset core на всех трёх поверхностях, fold-спайны
  сшиты общими вершинами, round caps на расстоянии α от core.
- Близкие параллельные швы: клип по средней линии, u_frac отражает
  реальную ширину половины.
- Замкнутое кольцо: 8 faces, miter-станции, wrap без щели.

## Интеграция

`_fill_manual_chain_decals` (SEAMS + Edge Select) вызывает
`build_seam_network_faces`; `_materialize_network_faces` кладёт faces в
bmesh с shared вершинами по ключам. Legacy miter/junction pipeline сохранён
целиком как fallback: настройка `decal_seam_network` (панель, default ON)
и автоматический откат при исключении/пустом результате. Unpaired
boundary edges остаются на `_build_boundary_wing_strip`.

Полный suite: `74 passed` (56 legacy + 18 network).

## Ограничения

- Кривые поверхности группируются по планарным патчам
  (`DECAL_COPLANAR_DOT` + допуск по plane distance): на сильной кривизне
  сеть деградирует к посегментным сайтам с connector-стыками. Band
  unrolling вдоль chain — следующая фаза (потребует расширения
  analysis-контракта: face-strip вдоль chain).
- Кривые биссектрисы (точка-против-сегмента) полилинизируются с допуском
  sagitta = `DECAL_WELD_DISTANCE`; на прямых биссектрисах (все junction
  cases) хорды точны. T-вершины вдоль общей прямой границы возможны, но
  коллинеарны и невидимы.
- Кольцо со сменой поверхностей получает служебный разрез на wrap-станции
  (UV-шов там же, где у legacy).
